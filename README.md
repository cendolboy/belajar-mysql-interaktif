## 📚 Apa Saja yang Akan Kita Pelajari?

Modul ini disusun berdasarkan kurikulum peminatan Informatika SMA/SMK dengan 8 urutan materi utama:

| No | Modul Pembelajaran | Topik & Deskripsi Materi |
| :---: | :--- | :--- |
| **1** | ➕ **Operator Aritmatika** | Operasi hitung pada data angka (`+`, `-`, `*`, `/`, `%` / `MOD`) untuk menghitung denda, diskon kantin, dll. |
| **2** | 🔍 **Operator Perbandingan** | Membandingkan nilai data (`=`, `!=`, `<`, `>`, `<=`, `>=`, `BETWEEN`, `IN`) untuk menyaring data spesifik. |
| **3** | 📊 **Fungsi Agregator** | Mengolah sekelompok data menjadi statistik ringkas (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`). |
| **4** | 🔤 **LIKE & Wildcard** | Pencarian teks fleksibel & spesifik (`%`, `_`, `LIKE BINARY` sensitif huruf, serta karakter `ESCAPE`). |
| **5** | 📈 **Pengurutan (ORDER BY)** | Mengurutkan data dari terkecil ke terbesar (`ASC`) atau sebaliknya (`DESC`) serta pengurutan bertingkat. |
| **6** | 🏷️ **Pengelompokan (GROUP BY)** | Mengelompokkan data berdasarkan kategori serta menyaring hasil kelompok menggunakan klausa `HAVING`. |
| **7** | 🔗 **Relasi Tabel (JOIN)** | Menggabungkan data dari beberapa tabel sekolah (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`). |
| **8** | ✏️ **Manipulasi Data (DML)** | Perintah penambahan data (`INSERT` Single/Multiple/Select), pembaruan data (`UPDATE`), dan penghapusan (`DELETE`). |

## ✨ Fitur Unggulan Modul

- 🏫 **Analogi & Skema Realistis Sekolah**: Database menggunakan contoh tabel siswa, nilai ujian, ekstrakurikuler, dan perpustakaan sekolah.
- 📋 **Tabel Referensi Super Rapi**: Dilengkapi fungsi query, penjelasan bahasa awam, sintaks lengkap, dan tombol **"Copy Code"** 1-klik.
- 💻 **SQL Live Sandbox / Simulator**: Ketik query kamu sendiri atau pilih *preset query* untuk melihat hasilnya secara langsung.
- 🧪 **Kuis Evaluasi Interaktif**: Uji pemahamanmu dengan 10+ soal pilihan ganda, kalkulasi skor otomatis, dan pembahasan detail.
- 🌙 **Dark / Light Mode**: Tampilan nyaman di mata untuk belajar siang maupun malam hari.
- 🖨️ **Export / Cetak Lembar Kerja**: Siap dicetak ke format PDF sebagai lembar tugas harian atau portofolio siswa.
